# Social Links Profile

A responsive social links profile card built as part of a [Frontend Mentor](https://www.frontendmentor.io/) challenge using HTML and CSS.

## Overview

This project is a personal social links profile page that displays my profile picture, name, location, a short introduction, and links to my social media profiles.

The goal was to recreate the provided design as closely as possible while practicing clean HTML structure, CSS styling, and responsive web design.

- Responsive profile card layout

- Semantic HTML structure

## What I Learned

While working on this project, I improved my understanding of:

- Structuring web pages using semantic HTML.
- Using CSS Flexbox to align and organize elements.
- Working with margins, padding, spacing, and typography.
- Creating interactive hover states for links.
- Managing images and relative file paths.
- Using Git and GitHub for version control.
- Publishing a static website using GitHub Pages.
